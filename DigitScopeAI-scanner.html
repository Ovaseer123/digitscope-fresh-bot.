Every digit X has a bucket holding the digits that came right after its last 100 occurrences. Each tick, the new digit is added to the bucket of the digit before it (the oldest item drops out when the bucket is full) and the counts are updated. The bucket's winner changes only if another digit's count is more than 2 higher than the current winner's count (3 or more ahead); otherwise the old winner stays. For example, with 6:30 and 7:28, a new 7 makes it 6:30, 7:29 and the winner stays 6. The mesh above is drawn from the same buckets the prediction uses: the green arrow is the winner of the last digit's bucket. The prediction for the next tick is that winner, and every tick records the previous prediction as a match or miss. The 500 history ticks are fetched in one request, so each bucket starts with about 50 items and grows to 100 as live ticks arrive. A single digit is ~10% likely on every tick, so the match rate averages about 10% however the buckets are counted.
